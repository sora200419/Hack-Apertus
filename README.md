# OriginPass CH–CN · Hack Apertus 2026 (Track 2B)

Sovereign rules-of-origin copilot for Swiss SMEs exporting to China, built on **Apertus**,
Switzerland's open LLM.

The project lives in [`track_2b/`](track_2b/) (official Hack Apertus template layout).

```bash
cd track_2b
make run        # http://localhost:8080 – works without an API key (replay cache)
```

See [`track_2b/README.md`](track_2b/README.md) and
[`track_2b/technical_report.md`](track_2b/technical_report.md).
